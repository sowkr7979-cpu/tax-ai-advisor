00 한 장 요약 (Executive Summary)

8개사 분석 결과 두 가지 결론이 분명합니다.

결론 1 — 업계가 한목소리로 "AI는 반복업무, 사람은 전략"이라 말한다.

  • 더존(세무): "AI가 반복업무를 없애주니 세무사는 컨설팅·최종검토에 집중"
  • AiLex(법률): "'문서 노가다' 대신 '승소 전략'에 집중하게 만든다"

→ 고부가 전략·복잡 판단 영역은 모든 제품이 사람에게 남겨두고 있다. 이 "빈 자리"가 곧 딜로이트 안진이 파는 영역이자 우리의 기회.

결론 2 — 업계 정석 아키텍처가 존재하며, 우리 설계는 이미 그것과 일치한다.

공통 패턴: ① 전문가 지식을 담은 Skills/워크플로 · ② 권위 자료 grounding + 근거(인용) 표시 · ③ 검증(팩트체커) · ④ HITL/Agentic(AI 계획→사람 승인→실행) · ⑤ 사건/맥락 단위 메모리

누구도 갖지 못한 우리만의 영역: 정답이 존재하는 세무 "계산층"의 Ground Truth 검증 + 회계사 직접 개발 서사. (법률 6사 = 해석층 인용검증까지 / 더존 = 공제 적용확인까지 / 계산검증 + 고차 전략판단은 8개사 모두 공백)

02 회사별 분석

2-1. 더존비즈온 — WEHAGO T / ONE AI 세무 · 직접 경쟁자

  • 정체: 국내 세무회계 ERP 지배자. WEHAGO T 위의 AI 레이어 "ONE AI". 태그라인 "AX, beyond DX".
  • 철학: "질문에 답"이 아니라 "일을 미리 해둔다". Function Call로 실행까지.
  • 이미 하는 것: AI 법인세무조정(150+ 서식→58개 자동작성, 세액공제·감면 요건 자동평가, "3시간→5분") · 법인세/종소세/원천세 전자신고 · 세법도우미(법령·예규·판례 grounding Q&A, 공제누락 탐지). 실제 프롬프트는 전부 컴플라이언스/적용확인 성격.
⚠ 위협 · "기본 세무조정·신고·일반 세법 Q&A"는 더존이 무료·ERP연동·대량으로 이미 제공 → commoditized. 정면 경쟁은 비현실적.
✅ 기회 · 더존조차 "전략·복잡 판단은 사람"이라 선언 → 고부가 전략 자문(M&A·국제조세·이전가격·세무조사·그룹구조)은 공백 = 안진의 영역.

면접 방어: "더존은 컴플라이언스를 표준화했고, 그래서 회계사 가치는 전략·복잡 판단으로 이동했습니다. 제 솔루션은 바로 그 지점을 AI로 확장합니다 — 더존은 데이터를 만들고, 저는 그 위에서 판단을 돕습니다."

2-2. AiLex(아이렉스) — A2D2 법률 · 좁은 웻지

  • 정체: 송무 "증거분석"에 초집중한 좁고 깊은 수직 제품.
  • 기능: 증거 검색(자연어+증거번호 인용) · 금융거래 PDF → 1초 만에 엑셀 변환·분석 · 하이라이트 서면 생성 · OCR 99%·타임라인·인물관계도·진술 상충 자동.
  • 카피: "'문서 노가다' 대신 '승소 전략'에 집중".

우리 시사점: 웻지 전략(한 고통지점 깊게) + "증빙·전표 PDF → 세무 데이터 자동 추출·검증" 메커니즘 직접 대응.

2-3. LexisNexis — Lexis+ with Protégé 법률 · ★설계 정당화

  • ★ 엔진이 Anthropic Claude: Claude + "Skills", "LexisNexis와 Anthropic 전문가가 함께 개발".
  • 3층 구조: Work(Agentic, 계획→승인→실행) · Skills(전문가 설계 지침) · Workflows(반복 표준업무).
  • 검증: 권위 콘텐츠 grounding + 인용 제공 + Shepard's. 2,000+ 전문가, RELX Responsible AI.

우리 시사점: 우리 설계(세무 Skills + 자동화 + HITL + grounding)와 1:1 일치 → "내 설계는 세계 1위 법률 AI 구조를 따른다". "내 Claude Code = Protégé의 Claude/Skills 패러다임" 서사. 단, 그들도 계산층 검증은 없음.

2-4. LBOX(엘박스 3.0) 법률 · "리걸 OS"

  • 정체: 국내 최대 판례 DB 기반 "리걸 OS"(1,600+ 고객사). "검색 + AI 질의 + 문서 작성을 하나로, 사건 단위로 맥락 누적".
  • 특징: 답변에 실제 판례번호·법조문 직접 인용(근거 가시화) · 사건 단위 맥락 누적 · 사용자 정의 워크플로.

우리 시사점: "법인세 업무 OS" 포지셔닝 + 근거 인용 가시화 + (LBOX엔 없는) 계산 검증.

2-5. 슈퍼로이어(SuperLawyer) — Law&Company 법률 · 메인스트림

  • 정체: 로톡 운영사의 "슈퍼 에이전트". 3.4만+ 법조인. 생태계 = 슈퍼로이어 + 빅케이스(458만 판례) + 업무관리.
  • 스킬 5종: 리서치 / 사건 기반 대화 / 초안 / 요약 / 인용 정확성 평가.
  • ★ 신뢰성: 팩트체커(답변 전 신뢰성 재확인, 특허 3건 출원) · 사건 메모리.

우리 시사점: "세무 팩트체커/검산기"를 간판 기능으로 — 그들은 인용(해석) 검증, 우리는 계산(정답) 검증이라 더 강함. "사건 메모리 ↔ 거래처 메모리".

2-6. 네플라 — 리걸독스 와이즈 프로 법률 · ★프레이밍

  • 정체: 변호사 서면 특화 워크플로우 AI(스타트업). "사건을 이해하는 만능 어쏘(주니어)".
  • ★ 핵심 메시지: "단순히 답변을 생성하는 AI가 아닙니다. 변호사의 사고 과정을 담았습니다."
  • 3단계: 자료 정리·기록 → 분석(자료·판례·쟁점·증거) → 서면 작성.

우리 시사점: 카피 차용 — "답변 생성 챗봇이 아니라 회계사의 사고 과정을 담은 AI". 3단계 = 우리 레이어(정리→분석→산출)와 일치.

2-7. 세무법인 넥스트 — TALA 세무 · 비중첩

  • 정체: 고액자산가 종합 컨설팅 세무법인. "BEYOND TAX". 상속·증여·가업승계 중심.
  • AI 3종: 상속 MBTI / TALA AI(챗봇) / 감정평가 AI — 전부 B2C 유입·진단형. 기술은 IT사(ITCEN ENTEC) 외주.

우리 시사점: 넓고 얕은 B2C+외주 vs 우리(좁고 깊은 법인세+직접개발). 시장 비중첩 → 차별 선명. 차용: "진단형 진입 데모"(절세 가능액 즉시 진단).

2-8. Microsoft Copilot 수평 플랫폼

  • 정체: 앞 7사와 다른 수평 엔터프라이즈 AI 플랫폼(그 위에 짓는 토대). 한국어 OCR 일부 불확실.
  • 구성: M365 Copilot(Word·Excel·PPT·Teams, Microsoft Graph grounding) / Copilot Studio(로우코드 커스텀 에이전트) / Scenario Library + KPI 프레임워크.

우리 시사점: Excel Copilot ↔ 세무조정(엑셀) · Copilot Studio ↔ 세무 Skills 정당화 · KPI/ROI 정량화 틀 차용 · ★ "안진 M365 스택에 *접목*" 전략(경쟁 아닌 보완).

03 종합 시사점 & 포지셔닝 옵션

3-1. 우리 설계의 정당성 (확인됨)

8개사 공통 정석(Skills + grounding + 검증 + HITL/Agentic + 맥락 메모리)과 우리 설계가 일치 → "직관으로 잡은 구조가 업계 표준"임이 입증. 면접에서 "왜 이렇게 설계했나"에 자신 있게 답할 근거.

3-2. 우리만의 차별점 (확인됨)

  • 계산층 Ground Truth 검증: 세무 = 계산(정답 존재) + 해석(판단) 2층. 8개사 누구도 계산 검증 없음 — 회계사만 설계 가능.
  • 회계사 직접 개발: 벤더·외주 대비 "도메인 전문가가 직접 만든다"는 서사.

3-3. 포지셔닝 결정 (— 타겟 도출 대화에서 확정. 상세: 타겟_정의서)

더존이 "토탈 컴플라이언스"를 이미 장악 → "토탈 솔루션" 정면 경쟁은 비현실적. → (a) 전략층 상향으로 결정.

  • ★ 확정: (a) 전략층 상향 — 절세 전략 시나리오 생성기(과세·방어 양면 + 근거 인용 + 계산·근거 검증 + HITL), 구조 중심 데모. 더존/AiLex가 비워둔 고부가 전략 영역 = 안진 영역과 일치.
  • (보조) (b) 웻지 — AiLex式 "증빙 PDF→세무데이터 추출·검산"은 데모 구성요소로 흡수.
  • 공통 신뢰 기반 = 계산층 검증(8개사 공백, 우리만의 영역).
