Target Definition · 1-Page

타겟 정의서 — 법인세 절세 전략 AI

1차 목표 · 딜로이트 안진 Tax/세무본부 합격 (작년 감사 탈락 → 세무 전환 지원). AI = 나를 뽑게 만드는 증명.
정체성 · "AI를 직접 만드는 회계사" — 도메인이 본체, AI가 무기.

한 줄 타겟

"감사로 검증을 체화한 회계사가,
검증 가능한 법인세 절세 전략 AI를 만든다."

01 킬러 데모 — 절세 전략 시나리오 생성기 (구조 중심)

입력가결산 재무데이터 + 상황 설명 텍스트 (둘 다)
처리절세 시나리오 생성 → 각 방안별 과세논리 vs 방어논리 양면 제시
근거실제 법령·예규·판례 인용 + 출처표기 (grounding)
검증 (감사 DNA)① 절세효과 계산 검증(Ground Truth) + ② 방어논리 근거 검증 — 둘 다
판단AI는 선택지·수치·근거만, 최종 판단은 회계사(HITL)
소재가볍게(예: 세액공제·감면 유불리). "작동 구조/아키텍처"를 보여주는 데 집중
산출 범위면접 전까지 설계도 + 화면 목업, 2~3개 흐름 (작동 데모는 다음 단계)
재무데이터·상황 입력 → 절세 시나리오 생성 → [방안별] 과세논리 / 방어논리 + 근거 인용 → 계산·근거 검증 → 회계사 판단

02 왜 이게 이기는가 (8개사 대비)

더존 위층 + 누구도 없는 계산층 검증 → "더존 위층, 안진 영역." (더존은 공제 적용 확인까지; 나는 유불리 시뮬레이션 + 과세·방어 + 검증까지)
과세·방어 양면 제시 = 리스크까지 스스로 까는 구조 → 깊이 후벼파기 방어 + 감사적 회의(skepticism) 증명
"구조"를 보여줌 = "AI 만드는 회계사" 정체성의 진짜 flex (특정 절세 깊이 경쟁 회피)

업계 8개사 공통 메시지 = "AI는 반복, 사람은 전략" → 전략·판단 영역은 모두가 비워둔 자리 = 내 기회.

03 서사 · 정직성 · 훅

서사 아크: 작년 감사 탈락 → 1년간 직접 AI 개발(세무조정·리서치 PoC) → 법무·세무 AI 8개사 벤치마킹 → 감사 검증력을 'AI 신뢰성'으로 옮긴 절세 전략 AI 설계.

정직성 전략 (세무 깊이 이슈): "세무 전문성은 쌓는 중입니다. 대신 감사로 단련한 검증력 + AI로 빠르게 메우고, 과세·방어 양면 + 회계사 최종판단(HITL) 구조로 과신을 방지합니다."

면접 훅 (정체성 선언)

"감사로 검증을 배운 회계사가,
신뢰할 수 있는 세무 전략 AI를 만듭니다."

04 내일 토의에서 정할 것

  • 절세 소재 1개 최종 확정 (가볍게 — 세액공제 유불리 유력)
  • 목업 화면 수 · 어떤 흐름 2~3개
  • 기존 PoC(세무조정·리서치) 재활용 범위
  • 정량 ROI(시간 절감 등) 수치 — Copilot式 KPI 틀 차용
  • "더존이 이미 하잖아?" 답변 스크립트 다듬기
