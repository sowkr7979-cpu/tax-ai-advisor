# 경쟁사 AI 벤치마크 분석 — 법률·세무 AI 8개사

> 목적: 법인세 토탈 세무 솔루션 AI 설계를 위한 경쟁/참조 사례 분석 (회계사 토의·지원 자료용)
> 대상 8개사: 세무법인 넥스트 · LexisNexis · 네플라 · LBOX · 슈퍼로이어 · 더존 · AiLex · Microsoft Copilot
> 분석 방법: 각 사 홈페이지(WebFetch) + 팜플렛(이미지 정밀 판독) + 뉴스/검색 교차검증

## 0. Executive Summary — 한 장 요약

8개사를 분석한 결과, **두 가지 결론**이 분명합니다.

**결론 1 — 업계가 한목소리로 "AI는 반복업무, 사람은 전략"이라고 말한다.**
- 더존(세무): *"AI가 반복업무를 없애주니 세무사는 컨설팅·최종검토에 집중"*
- AiLex(법률): *"'문서 노가다' 대신 '승소 전략'에 집중하게 만든다"*
- → **고부가 전략·복잡 판단 영역은 모든 제품이 사람에게 남겨두고 있다.** 이 "빈 자리"가 딜로이트 안진이 파는 영역이자, 우리 솔루션의 기회.

**결론 2 — 업계 정석 아키텍처가 존재하며, 우리 설계는 이미 그것과 일치한다.**
- 공통 패턴: **① 전문가 지식을 담은 Skills/워크플로 ② 권위 자료에 grounding + 근거(인용) 표시 ③ 검증(팩트체커) ④ HITL/Agentic(AI가 계획→사람이 승인→실행) ⑤ 사건/맥락 단위 메모리 누적**
- **누구도 갖지 못한 우리만의 영역**: 정답이 존재하는 **세무 "계산층"의 Ground Truth 검증** + **회계사가 직접 개발**했다는 서사.
  - 법률 6사 = "해석층"의 인용 검증까지. 세무의 더존도 "공제 적용 여부 확인"까지.
  - **계산 검증 + 고차 전략 판단**은 8개사 모두 공백.

## 2. 회사별 분석

### 2-1. 더존비즈온 — WEHAGO T / ONE AI (★ 직접 경쟁자, 동일 도메인)
- **정체**: 국내 세무회계 ERP 지배자. WEHAGO T 플랫폼 위의 AI 레이어 "ONE AI". 태그라인 **"AX, beyond DX"**.
- **철학**: "질문에 답"이 아니라 **"일을 미리 해둔다"**(출근하면 오늘 할 일이 이미 작성됨). **Function Call로 실행까지** 수행.
- **이미 하는 것**:
  - **AI 법인세무조정**: 150+ 신고서식 분석 → 58개 핵심서식 자동작성, 전년 데이터 자동채움, **세액공제·감면 요건 자동평가**. *"3시간 → 5분"*.
  - **AI 신고**: 법인세·종소세·4대보험·원천세·지방소득세 전자신고.
  - **세법도우미**: 법령·예규·판례 grounding 실시간 Q&A, 공제 누락 탐지, 데이터 정합성 검증.
  - 실제 프롬프트 예: "고용증대세액공제 받을 수 있는지 확인해줘", "청년창업중소기업감면 대상 업체 알려줘", "재무제표 이상 전표 찾아줘" — **전부 컴플라이언스/적용확인 성격**.
- **신뢰성**: RAG(최소 연관 데이터)+접근권한 제한, 기업 데이터 기반 오류 최소화. 한계 인정("최신정보와 다를 수 있음"). 사용 LLM 비공개.
- **우리 시사점 (가장 중요)**:
  - ⚠️ **위협**: "기본 세무조정·신고·일반 세법 Q&A"는 더존이 무료·ERP연동·대량으로 이미 제공 → **commoditized**. 정면 경쟁 비현실적.
  - ✅ **기회**: 더존조차 "전략·복잡 판단은 사람"이라 선언 → **고부가 전략 자문(M&A·국제조세·이전가격·세무조사 대응·그룹구조)은 공백** = 안진의 영역.
  - **면접 방어**: *"더존은 컴플라이언스를 표준화했고, 그래서 회계사 가치는 전략·복잡 판단으로 이동했습니다. 제 솔루션은 바로 그 지점을 AI로 확장합니다 — 더존은 데이터를 만들고, 저는 그 위에서 판단을 돕습니다."*

### 2-2. AiLex(아이렉스) — A2D2 (법률 / 좁은 웻지)
- **정체**: 송무 **"증거분석"에 초집중**한 좁고 깊은 수직 제품. *"변호사를 위한 AI 증거분석 서비스"*.
- **기능**: ① 증거 검색(자연어 + 증거번호 인용) ② **금융거래 PDF → 1초 만에 엑셀 변환·분석** ③ 하이라이트 서면 생성("AI 아닌 변호사가 쓴 듯") ④ OCR 99%(카톡·통장)·타임라인·인물관계도·진술 상충 자동 도출.
- **보안**: 100% 폐쇄형 자체 AI, 사건별 독립 DB, 학습 미사용.
- **카피**: *"'문서 노가다' 대신 '승소 전략'에 집중하게 만든다"*.
- **우리 시사점**:
  - **웻지 전략 교훈**: "전부"가 아니라 한 고통지점을 극단적으로 깊게. → 우리도 "토탈"보다 날카로운 웻지 1개가 현실적.
  - **PDF→엑셀 추출 메커니즘** ↔ "재무제표·전표·증빙 PDF → 세무조정 데이터 자동 추출·검증"으로 직접 대응 가능.

### 2-3. LexisNexis — Lexis+ with Protégé (법률 / ★ 설계 정당화 레퍼런스)
- **정체**: 세계적 법률정보 기업의 성숙한 Agentic 법률 AI. *"Transform your legal work"*.
- **★ 핵심 발견 — Anthropic Claude 기반**: 엔진이 **Claude + "Skills"**. *"LexisNexis와 Anthropic의 분야별 전문가가 함께 개발"*.
- **3층 구조**:
  - **Work(Agentic)**: AI가 단계 계획 제안 → 사용자 검토·승인 → 실행 (= HITL).
  - **Skills**: 특정 업무용 *전문가 설계 지침*(LexisNexis Skills / Claude General·Practice Area Skills).
  - **Workflows**: 반복 표준업무.
- **검증**: 권위 콘텐츠 grounding + 인용·참조 제공 + Shepard's 인용검증. 2,000+ 전문가 개발, RELX Responsible AI(인적 감독). 다중모델 아키텍처, Private model, Vault.
- **우리 시사점**: 우리 설계(세무 Skills + 반복 자동화 + HITL + grounding)와 **1:1로 일치** → "내 설계는 세계 1위 법률 AI의 구조를 따른다"는 강력한 정당성. *"내가 쓰는 Claude Code = LexisNexis가 Protégé를 만든 그 Claude/Skills 패러다임"* 서사. **단, 그들도 계산층 검증은 없다.**

### 2-4. LBOX(엘박스 3.0) — (법률 / "리걸 OS" 모델)
- **정체**: 국내 최대 판례 DB 기반 **"리걸 OS"**. 1,600+ 고객사. *"법률가를 위한 단 하나의 AI 업무 환경"*.
- **정의**: *"검색 + AI 질의 + 문서 작성을 하나의 흐름으로 통합하고, 사건 단위로 업무 맥락을 누적하는 리걸 OS"*.
- **특징**: ① 검색→AI 질의→작성 흐름 ② **답변에 실제 판례번호·법조문 직접 인용**(환각 방지를 근거 표시로 증명) ③ 사건 단위 맥락 누적 ④ 사용자 정의 워크플로. RAG + "국내 최초 Legal AI Agent".
- **우리 시사점**: **"법인세 업무 OS"** 포지셔닝 차용 가능(검색+질의+작성+거래처 단위 맥락 누적). 근거 인용 가시화 + (LBOX엔 없는) 계산 검증까지.

### 2-5. 슈퍼로이어(SuperLawyer) — Law&Company (법률 / 가장 메인스트림)
- **정체**: 로톡 운영사(국내 No.1 리걸테크)의 *"슈퍼 에이전트"*. 3.4만+ 법조인 사용. 생태계 = 슈퍼로이어 + 빅케이스(판례 DB) + 업무관리.
- **기술**: 자체 아키텍처 + **복수 상용 LLM(멀티모델)** + RAG. 데이터 **458만건 판례** + 박영사 주석서 독점.
- **스킬 5종**: 판례·법률 리서치 / 문서·사건 기반 대화 / 초안 작성 / 문서 요약 / **인용 정확성 평가(특화 기능)**.
- **★ 신뢰성**: **팩트체커(Fact Checker)** — 최종 답변 전 신뢰성 재확인, **허위정보 생성 방지 특허 3건 출원**. **사건 메모리**(매번 설명 불필요).
- **우리 시사점**: **"세무 팩트체커/검산기"를 간판 기능으로** 브랜딩 — 그들은 *인용(해석)* 검증, 우리는 *계산(정답 존재)* 검증이라 더 강한 주장. "사건 메모리 ↔ 거래처/기업 세무 메모리".

### 2-6. 네플라 — 리걸독스 와이즈 프로 (법률 / ★ 프레이밍 차용)
- **정체**: 변호사 서면 업무 특화 워크플로우 AI(스타트업). *"사건을 이해하는 만능 어쏘(주니어)"*.
- **★ 핵심 메시지**: **"단순히 답변을 생성하는 AI가 아닙니다. 변호사의 사고 과정을 담았습니다."**
- **3단계**: ① 자료 정리·기록 관리(OCR) → ② 자료·판례·쟁점·증거 분석 → 서면 목차 구조화 → ③ 서면 작성.
- **우리 시사점**: 카피 차용 — *"답변 생성 챗봇이 아니라 **회계사의 사고 과정을 담은 AI**"*. 3단계가 우리 레이어(정리→분석→산출)와 일치.

### 2-7. 세무법인 넥스트 — TALA (세무 / 비중첩, 차별 확인용)
- **정체**: 고액자산가·기업 종합 컨설팅 세무법인. *"BEYOND TAX"*. 상속·증여·가업승계·법인전환 중심.
- **AI 3종**: 상속 MBTI / TALA AI(24h 챗봇) / 감정평가 AI — **전부 B2C 유입(funnel)·진단형**.
- **기술**: 직접 개발이 아니라 **IT사(ITCEN ENTEC) 외주** 협업("TALA-CEN 2026"). 신뢰성 설계 공개 언급 없음.
- **우리 시사점**: 넥스트=넓고 얕은 B2C 유입+외주 / 우리=좁고 깊은 법인세 자동화+직접 개발. 시장(개인 자산가 vs 기업) 비중첩 → 차별 선명. 차용할 점은 **"진단형 진입 데모"**(예: 절세 가능액 즉시 진단) 1종.

### 2-8. Microsoft Copilot — (수평 플랫폼)
- **정체**: 앞 7사와 카테고리가 다른 **수평 엔터프라이즈 AI 플랫폼**(그 위에 올려 짓는 토대). 팜플렛 "M365 Copilot Agent / Legal AI Agent"(발행 MDA). *한국어 OCR 일부 불확실*.
- **구성**: M365 Copilot(Word·**Excel**·PPT·Outlook·Teams, Microsoft Graph로 사내 데이터 grounding) / **Copilot Studio**(로우코드 커스텀 에이전트 구축) / Scenario Library + **KPI 프레임워크**.
- **우리 시사점**:
  - **Excel Copilot ↔ 세무조정**(엑셀 중심 작업) 직접 대응.
  - **Copilot Studio 커스텀 에이전트** = 우리 "세무 Skills/에이전트" 정당화.
  - **KPI/ROI 정량화 틀** 차용 → WHY·로드맵에 "시간·비용 절감 %" 도입.
  - **★ 전략 포인트**: 딜로이트 등 빅4는 M365·Copilot 스택 → 우리 솔루션을 "Copilot 생태계와 *경쟁이 아니라 접목* 가능한 세무 도메인 레이어"로 포지셔닝하면 "우리 스택에 맞는다"는 강점.

## 3. 종합 시사점 & 포지셔닝 옵션

### 3-1. 우리 설계의 정당성 (확인됨)
8개사 공통 정석(Skills + grounding + 검증 + HITL/Agentic + 맥락 메모리)과 우리 설계가 일치한다. 즉 "직관으로 잡은 구조가 업계 표준"임이 입증됨 → 면접에서 *"왜 이렇게 설계했나"*에 자신 있게 답할 근거.

### 3-2. 우리만의 차별점 (확인됨)
- **계산층 Ground Truth 검증**: 세무는 "계산(정답 존재) + 해석(판단)" 2층. 8개사 누구도 계산 검증을 갖지 못함. 회계사만 설계 가능.
- **회계사 직접 개발**: 더존(외주 아님이나 벤더)·넥스트(외주) 대비, "도메인 전문가가 직접 만든다"는 서사.

### 3-3. 포지셔닝 결정 *(— 타겟 도출 대화에서 확정. 상세: `타겟_정의서.md`)*
