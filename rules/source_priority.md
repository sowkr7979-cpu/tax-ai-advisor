# rules/source_priority — 권위 우선순위 (docs/README §5, docs/04 §6)

종합(synthesis) 시 충돌 조정 기준. **가중 평균 금지** — 권위·시점이 지배한다.

| rank | 출처 | 비고 |
|---:|---|---|
| 1 | 법률 (법인세법 등) | 최상위 |
| 2 | 시행령 | 위임범위 내 보충 |
| 3 | 시행규칙 / 고시 | |
| 4 | 예규 · 질의회신 | 해석, 법령 override ✕ (구속력 한계) |
| 4 | 판례 · 심판례 | 해석·구체화, 확정 변수 |
| 5 | 라이선스 실무서 | L1 |
| 6 | 웹 (공식) | SourceSnapshot, 최후순위 |

규칙:
- **다수결 금지**: 소수라도 상위 권위·유효 최신법이면 그것이 지배.
- **시점 우선**: 적용시점(거래일/귀속/신고)에 유효한 버전이 우선 (PROV-012).
- **사실 불일치 배제**: fact_pattern이 다른 근거는 충돌이 아니라 무관으로 배제.
- **미해소 충돌**: 평균내지 말고 `ConflictResolution(outcome=UNRESOLVED_ABSTAIN)` +
  회계사 검토항목으로 escalate (docs/08 §5-1).

> 이 파일은 slice ④(충돌 종합) 구현 시 결정테이블로 코드화된다. 현재는 참조 명세.
